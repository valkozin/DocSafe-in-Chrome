Turn your browser into a secure, private file safe. "Local File Vault" allows you to password protect and encrypt files without them ever leaving your computer.

🔒 100% PRIVATE & OFFLINE - NO DATA UPLOAD
Unlike other tools that upload your files to a cloud server, Local File Vault processes everything locally within Chrome. Your files never touch the internet. You are the only one who holds the key.

📂 HOW IT WORKS
1. Open the extension.
2. Drag and drop any file (Photos, PDFs, Docs, etc.) into the vault.
3. Set a strong password.
4. Click "Encrypt" to download a secured version of your file immediately.
To decrypt, simply drag your locked file back into the extension and enter your password.
